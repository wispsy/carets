# Release notes

## Unreleased source profile

Adds owned command lifecycle/timers, scoped terminal modes/signals/restoration,
focus/event routing, typed forms/services and reusable synthetic application tests.
Existing update/view and field declarations remain supported. Program instances
now run once and close their owned input sources during shutdown. Native Windows
console input and advanced layout/rendering/protocol/widget roadmaps remain open.
These changes are source-qualified; no new version, tag or package upload is
selected by the composition milestone.

## 0.1.0

Initial dependency-free message loop, ANSI parser, cell rendering/styles, zones,
basic components and declarative forms.
